# Program Rekap dan Analisis Nilai Matematika Kelas

## Deskripsi

Proyek ini merupakan rancangan program sederhana menggunakan Python untuk membantu guru matematika mengolah data nilai siswa. Program dirancang untuk membaca data dari file teks, memvalidasi nilai, menghitung statistik, menentukan ketuntasan, dan menyimpan laporan.

## Tujuan

1. Menghitung rata-rata, nilai minimum, dan nilai maksimum.
2. Menentukan jumlah siswa tuntas dan belum tuntas berdasarkan KKM.
3. Menyimpan hasil analisis dalam file laporan.
4. Menerapkan konsep list, dictionary, fungsi, validasi, dan file I/O dalam Python.

## Struktur Folder

- `data/`: menyimpan data contoh.
- `src/`: menyimpan kode program.
- `tests/`: menyimpan test case.
- `output/`: tempat penyimpanan laporan.
- `proposal.md`: dokumen rancangan proyek.

## Teknologi

- Python 3
- Visual Studio Code
- Git
- GitHub

## Cara Menjalankan

Pada tahap rancangan, program belum selesai diimplementasikan.

Setelah implementasi selesai, program akan dijalankan melalui terminal VS Code menggunakan perintah:

`python src/main.py`

Perintah tersebut digunakan setelah file dan fungsi program selesai dibuat.

## Pengujian

Rencana pengujian tersedia pada `tests/test_case.md`. Pengujian meliputi perhitungan statistik, nilai batas, nilai tidak valid, file tidak ditemukan, dan ketuntasan.
